# 数据结构与算法学习记录

本仓库用于记录和整理本人在学习数据结构与算法过程中的代码实现与相关笔记。

## 目录结构
- Arrays/  —— 数组相关的代码与操作示例
- .vscode/ —— VS Code 配置文件（编译、调试等）

## 内容说明
- 包含顺序表、数组的插入、删除、查找等常见操作的 C++ 实现。
- 每个代码文件均为学习过程中的实际练习与总结。

## 适用对象
- 数据结构与算法初学者
- 需要 C++ 代码示例的同学

## 使用方法
1. 推荐使用 VS Code 打开本项目。
2. 相关编译和调试配置已在 .vscode 文件夹中给出。
3. 直接运行或修改各代码文件进行学习和练习。
